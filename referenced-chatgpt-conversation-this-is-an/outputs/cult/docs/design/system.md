## Source audit

The supplied HTML is reference material, not the implementation. Its black environment, Figtree, numbered navigation, asymmetric media and sparse magenta are retained. Its invented Vesper, In the Air and Halo Freight case studies, 4.2x ROAS, 18d and 2.1M claims are rejected. The supplied brief is the copy authority whenever it differs from the HTML. The cached conversation stops partway through the motion instructions; the current user's explicit accessibility, performance and QA requirements govern the remainder.

Six uploaded films were inspected at representative frames and probed for duration and dimensions. Four are useful production footage: fashion/jewelry (Creative), broadcast panels (Media), laser threshold (Conversion), and CRT infrastructure (Partner). The large pink rectangle is too dominant for the restrained accent direction; the aircraft/blossom scene is too pastel and unrelated to the capability metaphors. Both remain source references only.

Strategy uses the embedded campaign-selection photograph, Search the magnifying-glass photograph, Measurement the gauge photograph. These are deliberately still cinematic frames, not fake video or CSS movement pretending to be film. Their media manifests support future matching film replacements. Audit and Build use their own supplied stills. Partner has its own separate film; no capability film is recycled into engagements.

## Design system

- Background #050505; foreground #FFFFFF; secondary #C8C8C8; accent #FF2EB8; rules #333333. No gradients or colored overlays. Local Figtree regular, semibold and bold. Neutral system sans fallback.
- Gutters: desktop 64px, intermediate 40px, mobile 22px. Reading columns 32–40rem. Major sections use generous 96–144px spacing; mobile 64–80px.
- Type: hero identity 200px at 1440; hero headline 58px; architectural headings 96–144px; story headings 88–100px; body 18px; UI 14px. Mobile identity 108px, hero 38px, primary headings 46–54px, body 16px, UI 14px.
- Sharp outlined primary CTA, underlined secondary CTA, small SVG direction arrow. Minimum 44px interactive targets. Image corners up to 6px; no card system, decorative icons, shadows, pills or glow.
- Components: header/navigation, brand wordmark, action links, role selector, media stage, story frame, editorial engagement doors, honest work placeholders, founder text, contact form, footer.
- Motion variables: interface 160ms; media dissolve 650ms; easing cubic-bezier(.2,.7,.2,1). No scroll capture, animated text hiding, parallax or continuous CSS motion. Reduced motion suppresses autoplay and dissolves. Media pauses when out of view or document is hidden.

## Responsive and media behavior

Desktop hero is one full-bleed media stage, with subject on the right and brand copy on the left, role controls along the bottom. Default Creative uses a supplied film. At 1024 reduce type and gutters; at 768 the header becomes a small disclosure menu and film/copy separate into composed areas. At 390 and 360 story images sit above copy; minimum heights are flexible rather than forcing clipped full-screen panels.

Each film has silent fast-start 1440px and 640px versions. Posters are WebP; mobile poster sources use responsive pictures. No sources are attached to offscreen video. Only the active hero world mounts a video; role changes retain the previous poster for a dissolve. Mobile/save-data/slow connections default to posters with explicit playback. Keyboard arrow navigation and native focus via the installed tabs primitive; touch selection via click. A visible pause/resume control governs all film motion.

## Concept corrections required by source brief

Generated concepts are visual specifications subject to the supplied brief: ignore any invented navigation in the thesis/story images; preserve only the four numbered global links. Keep Figtree for the preference thesis even where generation suggests a condensed font. Use the original reference footage and stills, not generated lookalikes. The HTML reference is never reused as a template. Work placeholders intentionally remain typography instead of fabricated portfolio art.
