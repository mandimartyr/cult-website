# SIGNAL. image direction and generation record

Method: built-in image_gen. Nine concepts and three separate photographic campaign assets. Source paths: `assets.json`. All selected files copied into this repository; runtime does not depend on the generated-images directory.

## Shared concept brief

High-fidelity desktop website section for SIGNAL., fictional B2B intelligence inside CULT. Governing idea: information destroyed until the decision remains. Geometric Figtree-like sans, extremely large precise type and tiny monospaced commercial data; void #050505, paper #eae7df, graphite #202221, priority red #ef3b31. No gradients, rounded corners, card wrappers, stock photos or dashboard UI. Code-native readable copy and controls. Nine coordinated sections, each using the exact corresponding chapter copy from USER_BRIEF.txt.
