## Intentional constraints / deviations

- Preserve actual CULT Figtree; concept-only condensed fonts are not substituted into the existing brand system. Some line breaks therefore differ from the raster sketches. Typography is HTML, not a flattened screenshot.
- Preserve shared CULT nav/footer and next-study link. Do not copy invented navigation or metadata from generated sketches.
- Preserve original strategy/campaign rationale text even where the new execution expands beyond the original thermal-print metaphor. No new strategic claims, fabricated sources, real clients or results.
- Decorative noise is an `aria-hidden` information texture, not content a visitor must read. It deliberately dims below text contrast. Axe checks exclude only `.si-noise`; meaningful text, controls, actual example data and the rest of the page remain scanned.
- Use finite entry/processing sequences instead of endless noise updates. Reduced motion shows stable information, and controls remain usable.
- Priority compression uses a dimensionally stable stage rather than collapsing document height and causing a scroll jump. The visual information still disappears.
- Physical campaign environments are three generated photographic applications; digital creative is native full-scale type, not a fabricated live publisher/feed screenshot.
- The demo brief is explicitly local, in-memory review/edit. It neither schedules a meeting nor sends/stores the entered details. Actual enquiries use the existing CULT contact route.

Visual checks cover copy, hierarchy, typography, palette, container model, physical imagery, responsive spacing and motion. Opening copy is restricted to supplied SIGNAL/position/counts plus scene/self-initiated disclosure and the existing CULT shell. No extra CTA, product badges or invented offer were introduced above the fold.

Browser/IAB was used for live inspection first. Exact 1440/1280/1024/768/390/360 sizes use system Chrome/Playwright because IAB resizing was previously unreliable. Concepts and rendered screenshots were inspected with view_image, including desktop and mobile chapter views. Current acceptance evidence and build status are in QA.md.
