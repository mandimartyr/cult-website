## Design system
Figtree inherited from CULT for all display and body. Courier New for technical data. Void #050505, graphite #202221, paper #eae7df, priority red #ef3b31, watch #d4b853, normal #9fb598. Red conveys priority, not ornament. Responsive display 48–240px with tight tracking, 11px technical labels, 16px body. Square buttons, open canvas, typography constructs the interface. 56px desktop gutters, 20px phone. Paper brief as a full printed document; no rounded containers or shadows. Shared CULT magenta only in the shared shell.

## Interaction / motion
Opening: 150+ deterministic illustrative fragments, selective slow lateral movement and dimming over ~1s; content and primary label always immediately usable. No infinite noisy update loop; native pause control if ongoing motion is used. Filter: button-initiated compression from 72 changes to three priorities. Use fixed-stage dimensions, opacity/strike/short lateral movement; never create a large unexpected layout shift. Restore affordance. Final: deliberate advance/replay through three metrics, one conclusion, one action; no scroll traps. Cause is four actual spacious layers with no sticky trapping. Horizontal market data becomes stacked on phones.

Micro 140ms, interface 320ms, cinematic 900ms. Once-only clipping for selected type, opacity-only evidence, plenty of still statements. Reduced motion displays completed states without animation while retaining all controls and information. Motion observers clean up on route change.
